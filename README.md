# PolyTrack FX (unofficial mod)

An unofficial graphics mod for **PolyTrack**: day and night cycle, weather and wet roads, headlights, bloom, god rays,
ambient occlusion, cinematic cameras and a photo mode. Play it at https://notarqen.github.io/trackfx/

PolyTrack is made by [Kodub.com](https://www.kodub.com). To play the original game, visit
[the official page](https://www.crazygames.com/game/polytrack).

## Controls

On first open the game shows an intro card with these. Press **H** to see it again.

| key | action |
| --- | --- |
| **F9** | open / close the effects panel (every slider and toggle) |
| **H** | intro and controls screen (also the **?** button in the panel) |
| **C** / shift+C | cycle camera views |
| **K** | cinematic cameras on / off |
| **E** or **/** | headlights on / off |
| **P** | photo mode (free camera; press Space yourself to pause the race on the web build) |
| **shift+P** | instant photo (downloads a PNG) |

In photo mode: WASD move, Q/E down/up, drag to look, wheel zoom, Tab orbit the car, Enter capture, Esc exit.

If it runs slowly, open the panel and lower the quality preset or render scale under *performance*.
Settings are saved in your browser.
